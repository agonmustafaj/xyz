# Blerta Ferati — Portfolio

Premium personal portfolio for Blerta Ferati (BSc Computer Science).

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Edit content

All editable copy and placeholders live in:

- `src/data/content.ts`

Replace `YOUR_*` markers, placeholder project titles, contact links, and timeline years with real details. Do not invent professional facts.
